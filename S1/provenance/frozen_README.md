# DILSCM 会议论文实验代码

本目录为独立整理版。核心算法 `rmfs_core.py`、生成器 `synthetic_data.py`、参数 `protocol_config.json` 保留冻结文件的原始字节；`instances.py` 仅提取原实例构造函数，函数语法树不变。

使用PyCharm时，先按《复现教程.md》选择解释器，然后在项目列表依次右键运行01检查环境.py、02单种子重跑.py和03完整实验.py。这些入口不需要填写参数；04统计复算.py只复算已有明细。原.cmd脚本用于Windows文件资源管理器双击。`reference` 是逐项核对所需的参考结果，必须保留；`fresh` 模式不会读取其中的交换路径来选择交换。

| 文件 | 作用 |
| --- | --- |
| reproduce.py | 唯一的合成实验入口；调度、续跑、核对和报告 |
| experiment.py | 三档强度的统一搜索及展开；缓存重复布局评价 |
| instances.py | 冻结实例构造逻辑 |
| rmfs_core.py | 冻结分批、交换和选择算法 |
| synthetic_data.py | 冻结合成订单生成器与初始布局 |
| analysis.py | 无全局副作用的八张统计表 |
| figures.py | 从新统计表生成四组矢量PDF和300dpi PNG |
| io_utils.py | 原子检查点写入和严格结果比较 |
| tests/ | 原核心测试及独立评价器、续跑、统计输入检查 |
| optional/ | 真实数据及独立运行耗时的隔离入口 |

只有最终 `REPRODUCTION_REPORT.json` 为 `PASS` 才表示该次运行完整通过。单个检查点、部分CSV或控制台进度不能替代完成报告。

本包精简合成复现工作流，未复制历史文稿、预实验、V2探索和重复源码；原始压缩包及工作文件保留，未删除。

统计限于锁定100个种子和参数网格；`--seed` 可选择其中一个种子作单次检查。改变方法或参数属于新实验，不能继续使用本包的冻结一致性声明。
